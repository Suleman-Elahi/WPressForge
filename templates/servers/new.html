Install the agent

On a clean Ubuntu 24.04 or Debian 12 host, as root:

curl -fsSL https://get.wp-panel.dev/agent.sh | \
  WP_AGENT_TOKEN={{ suggested_token }} \
  WP_AGENT_BIND=0.0.0.0:8443 sh

The installer sets up Docker, Nginx, MariaDB, Restic and WP-CLI, then starts wp-agent as a systemd service. Nothing else needs to be exposed publicly except ports 80 and 443.
